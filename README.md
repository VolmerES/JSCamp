# JSCamp

Ejercicio del JavaScript Camp de midudev (2025): una landing en HTML y CSS puros, sin frameworks,
para *Gallery Swipe AI*, una app de galería de fotos con IA.

La gracia del ejercicio está en el HTML semántico y accesible: cabecera con navegación etiquetada,
`aria-labelledby` en cada sección, un formulario de búsqueda con su `label` oculto y textos alternativos
en las imágenes.

## Verlo

No hay que instalar nada: abre `index.html` en el navegador.

| | |
|---|---|
| `index.html` | La página |
| `styles.css` | Estilos |
| `logo.png`, `GalleySwipe.png` | Logo y captura de la app |

Los enlaces del menú a otras páginas (`features.html`, `download.html`…) y el botón de descarga son de
relleno: el ejercicio era solo la portada.
